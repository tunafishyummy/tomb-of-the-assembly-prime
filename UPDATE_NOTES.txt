Tomb of the Assembly - targeted gameplay update

Updated:
- Added a temporary thin yellow dash line rendered as a visual overlay. It is not stored in the room tiles and disappears when the dash ends.
- Reduced the level-complete heading size and shortened it to fit the screen.
- Added generated key + locked door, bomb, and movable crate placement. Doors consume a collected key.
- Seeded normal stages from their stage index so replaying the same stage produces a consistent generated map.

Build:
- In dos/, run `make` with GNU binutils installed.

Validation note:
- TOMB.COM assembles and links successfully.
- `make test` currently fails at tests/gen_check.py because the assembly generator output differs from the bundled C reference generator. This package should be gameplay-tested in DOSBox before being treated as final.
